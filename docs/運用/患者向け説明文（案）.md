# 自宅でのリハビリを続けるためのアプリについて（説明文 案・同意説明文書の素材）

順天堂医院 肝胆膵外科

## このアプリは何をするものですか

抗がん剤治療の間、手術に向けて体力を保つために、自宅でできる運動を動画でご案内します。毎日、運動ができたかどうかと体調を送っていただくと、担当のスタッフがその日のうちに確認します。気になることがあれば、スタッフからお電話や外来でお声がけします。

この取り組みは「アプリを使った自宅でのリハビリが無理なく続けられるか」を調べる研究として行います。参加は任意で、参加しなくても治療に不利益はありません。途中でやめることもできます。詳しくは別紙の同意説明文書をご覧ください。

## お名前などは送られません

- アプリには **4 桁の番号** だけが登録され、お名前・生年月日・診察券番号・住所・電話番号は入りません
- 番号と暗証番号はカードでお渡しします。入院中にスタッフが一緒に入力します
- 番号とあなたの対応、治療の内容や検査の結果は、病院の中の研究用データ管理システムでのみ管理します
- 送っていただく内容は、大学が契約しているシステム（Google Workspace）の、担当スタッフだけが見られる場所に保存されます
- 「ひとこと」欄には、お名前や住所など個人が分かることは書かないでください

## 毎日していただくこと

1. 毎日、目標の時間を目安に歩く
2. 週に 3 回、ご自身で決めた曜日にアプリの「セッションを始める」を押す。最初に体調を確認し、青なら通常の運動、黄なら 5〜10 分の軽い運動、赤なら中止になります
3. 運動が終わったら「運動後の体調を記録して送る」を押し、歩いた時間・きつさ・体調を選んで送る（1 分ほどです）
4. 赤で中止した日も、そのまま送ってください。担当者が確認します

## 注意していただくこと

- **このアプリは緊急の連絡には使えません。** 熱や強い痛みなど体調が悪いときは、必ず病院へお電話ください（外来: ○○-○○○○-○○○○）
- 赤信号で中止したときや運動後に症状が出たときは担当者に自動で知らせが届きますが、返答は診療時間内になります。急ぐときは必ずお電話ください
- スマートフォンやカードを紛失した場合は病院にご連絡ください。番号を無効にして新しいものをお渡しします
- アプリを削除すると、スマートフォンの中の記録は消えます（病院側の記録は残ります）

## やめたいとき

いつでもやめられます。担当スタッフにお伝えください。ご希望があれば、病院側に保存された記録も消去します。
