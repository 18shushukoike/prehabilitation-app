# セットアップガイド

順序どおりに進めると、患者からの送信が担当者のメールとスプレッドシートに届く状態になる。

## 0. 事前確認

- [ ] `docs/申請/情報管理部門確認資料.md` を情報管理部門・Workspace 管理者に提出し、可否を確認
- [ ] 科内で責任医師・担当者・電話対応ルールを決める（`docs/運用/` に手順書を置く）
- [ ] 患者向けに表示する電話番号（外来直通など）を決める

## 0.5 まず手元で動かしてみる（Google 側の準備前）

`tools/mock-server/README.md` のとおりモックサーバーと PWA の開発サーバーを起動すると、Mac と同じ Wi-Fi のスマートフォンから http://<Mac の IP>:5173 でアプリを開け、送信内容が http://localhost:8787 の画面とターミナルに届く。テスト患者は番号 `9001`（暗証番号 `0000`）。

見た目だけを確認するデモ版（送信なし）は `cd patient-pwa && npm run build:demo` で `patient-pwa/demo/術前リハ_デモ.html` に 1 ファイルとして出力される。

## 1. スプレッドシートと Apps Script

`apps-script/README.md` の手順で、共有ドライブ → スプレッドシート → スクリプト貼り付け → `setupSheets` → 設定タブに通知先 → `installTriggers` → ウェブアプリとして公開。**ウェブアプリの URL** を控える。

## 2. PWA の公開

```bash
cd patient-pwa
cp .env.example .env     # VITE_API_URL にウェブアプリの URL、電話番号、VITE_BASE
npm install
npm run build
```

`dist/` を GitHub Pages（プライベートリポジトリ）または学内 Web サーバーに置く。公開 URL をブラウザで開き、初期設定画面が出ることを確認する。

## 3. 動作テスト（ダミー ID）

1. `tools/id-generator/index.html` を開き、番号を `9001` にして **発行**（テスト用番号）
2. 出力された行をスプレッドシート「患者一覧」に貼り付け、`assignee_dr` に自分のメールを入れる
3. 自分のスマートフォンで PWA の URL を開き、ホーム画面に追加 → ホーム画面から開いて番号と暗証番号を入力
4. 「今日の記録を送る」でセッション「できなかった」＋理由を選んで送信
5. 「日次記録」に行が入り、即時通知メールが届き、全体サマリーと「進捗_9001」タブが更新されれば成功
6. 翌朝 8:00 に朝のまとめメールが届くことを確認
7. テストが終わったらダミー行の `status` を `inactive` にするか削除する

## 4. 動画の準備

- 撮影・編集後、YouTube 限定公開（大学アカウント）または大学 Drive にアップロード
- `patient-pwa/src/data/exercises.ts` の `videoUrl` に埋め込み URL を入れて再ビルド・再公開

## 5. 患者登録（入院時）

1. 発行ツールで番号・暗証番号を発行 → 患者一覧に行を貼り付け → 担当者を入力 → REDCap 等の院内システムに番号と患者の対応・臨床情報を登録
2. 患者のスマートフォンで PWA の URL を開き、ホーム画面に追加。ホーム画面から開いて、スタッフが一緒に番号と暗証番号を入力し、テスト送信
3. カードを患者に渡す。運動時間をアラームに登録するよう案内
4. 「体調が悪いときは病院へ電話。アプリは緊急連絡には使えない」ことを説明

## 6. 日々の運用

- 即時通知メール（赤信号・運動後の症状）が来たら内容を確認し、必要なら電話。対応記録タブに記入し、重要な所見は電子カルテにも記載
- 毎朝のまとめメールで予定日未実施・未送信・要連絡を確認し、必要な患者に電話
- 毎朝のまとめメールで未送信者・要連絡者を確認
- 外来受診時は「進捗_番号」タブを一緒に見ながら面談。握力・SPPB 等の評価値は REDCap 等に入力
- 手術・中断時は患者一覧の `status` を変更

## 7. コードを直したとき

- Apps Script: 貼り直して「デプロイを管理 → 新バージョン」（URL は変わらない）
- PWA: `npm run build` して再公開。患者の端末は次回起動時に自動更新される
