# 術前リハビリ支援ツールにおける Google Workspace 利用について（確認依頼）

肝胆膵外科
作成日: 2026-09-11

## 1. 目的

膵癌に対する術前化学療法中の患者に、自宅でのリハビリテーション（運動）を動画で案内し、毎日の実施状況と体調を患者のスマートフォンから送信してもらう。担当者はその日のうちに内容を確認し、必要な患者に電話や外来で声をかける。**前向きの単群 feasibility パイロット研究**として倫理審査委員会の承認と文書同意を得て実施する。

## 2. 確認したいこと

1. 大学契約の Google Workspace（共有ドライブ・スプレッドシート・Apps Script・Gmail）に、**下記 3 のデータ**を保存・処理する運用は認められるか。申請が必要な場合はその手続き
2. Apps Script のウェブアプリを「全員（匿名を含む）」に公開する設定が、大学の Workspace 管理設定で許可されているか（患者は Google アカウントを持たないため必要）
3. 上記が不可の場合、Google フォームへの「組織外からの回答」は許可されているか

## 3. 扱うデータ

| 区分 | 内容 | 保存場所 |
|---|---|---|
| 研究 ID | 4 桁の番号（1001〜）。患者との対応表は **REDCap 等の院内管理システム**で管理し、Google 上には置かない | Google スプレッドシート |
| 患者が送信する内容 | 歩いた分数、運動前の体調確認（選択式と自由記載）、運動セッションの実施（した／一部／できなかった）と種別・時間、できなかった理由、運動後の体調ときつさ（選択式）、ひとこと（自由記載） | 同上 |
| 運用情報 | メニューの種類、担当者のメール、有効／無効 | 同上 |
| 医療者の対応記録 | 電話で伝えた内容など | 同上 |

**Google 上に保存しないもの**: 氏名、生年月日、病院 ID、住所、電話番号、メールアドレス、化学療法の内容や日程、外来日、手術予定日、年齢、性別、身体機能の評価値。これらは REDCap 等の院内管理システムで研究 ID に紐づけて管理する。患者向け画面には「名前や住所は書かないでください」と表示する。

## 4. データの流れ

```
患者のスマートフォン（ブラウザアプリ、番号と暗証番号のみ保持）
   │ HTTPS で送信
   ▼
Apps Script（担当者の大学アカウントで実行。番号と暗証番号を照合）
   │
   ├─▶ Google スプレッドシート（共有ドライブ。科の担当者のみ）
   └─▶ 担当者の大学メールへ通知（研究 ID と入力内容のみ）
```

- スプレッドシートは患者に公開しない。患者はスプレッドシートにアクセスできない
- アプリ本体（HTML/JS）は患者データを含まないため、GitHub Pages または学内 Web サーバーに置く
- 動画は YouTube 限定公開または大学 Google Drive に置く（患者データを含まない）

## 5. 安全管理措置

- 共有ドライブのメンバーを科の担当者に限定。リンク共有・外部共有は無効
- 大学アカウントは 2 段階認証を必須とする。閲覧は原則院内 PC
- 患者の送信は 4 桁の番号と 4 桁の暗証番号（スプレッドシートにはハッシュのみ保存）で照合し、不一致は破棄。連続失敗でロック
- 患者から送信された記録は追記のみで手動編集不可（シート保護）。変更履歴・Apps Script 実行ログを監査記録とする
- 月 1 回、CSV を院内 PC にバックアップ
- 重要な所見（運動中止の目安に該当、体重減少、休止指示）は電子カルテにも記載する
- 患者の希望があれば当該研究 ID の行を削除する

## 6. 位置づけ

- 本ツールは診療録ではなく、研究データの収集手段である。重要な所見は電子カルテにも記載する
- 診断・治療判断を行う機能は持たない（プログラム医療機器に該当しない設計）
- 研究計画書に本資料の内容（データの保存先と安全管理措置）を記載し、倫理審査を受ける
