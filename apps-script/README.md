# Apps Script 配置手順

スプレッドシートに**バインドされた**スクリプトとして配置する（clasp は不要。コピー＆ペーストで動く）。

## 1. スプレッドシートの作成

1. 大学 Google アカウントで **共有ドライブ**（科の担当者のみメンバー）を作成する。個人の My Drive には置かない
2. 共有ドライブ内に新規スプレッドシートを作成。名前は例: `術前リハ_記録`
3. 共有設定: リンク共有オフ。共有ドライブのメンバー以外は追加しない

## 2. スクリプトの貼り付け

1. スプレッドシートのメニュー **拡張機能 → Apps Script**
2. 左の `コード.gs` の中身を削除し、`Code.gs` の内容を全て貼り付けて保存
3. 歯車（プロジェクトの設定）で **「appsscript.json」マニフェストをエディタで表示する** にチェック → 表示された `appsscript.json` を本フォルダの内容で置き換えて保存

## 3. 初期化

1. エディタ上部の関数選択で `setupSheets` を選び **実行**。初回は権限の承認画面が出るので、自分の大学アカウントで承認する
2. スプレッドシートに 6 つのタブ（患者一覧・日次記録・対応記録・全体サマリー・通知ログ・設定）ができる。患者ごとの「進捗_番号」タブは患者一覧に番号を追加した後の再計算で自動生成される
3. **設定** タブの `notify_emails` に即時通知の宛先（大学メール、カンマ区切り）を入れる。`summary_emails` は空なら `notify_emails` と同じ
4. 関数 `installTriggers` を実行（毎日 8:00 朝のまとめ、月曜 8:15 週次、毎時集計更新）

## 4. Web アプリとして公開

1. 右上 **デプロイ → 新しいデプロイ**
2. 種類: **ウェブアプリ**
3. 実行ユーザー: **自分**（デプロイする担当者の大学アカウント）
4. アクセスできるユーザー: **全員**（患者は Google アカウントを持たないため必須）
5. デプロイ → 表示される **ウェブアプリの URL**（`https://script.google.com/macros/s/.../exec`）を控える。これを PWA の `.env` の `VITE_API_URL` に設定する
6. ブラウザで URL を開き `{"ok":true,"service":"prehab",...}` が返れば公開できている

> 「アクセスできるユーザー」に「全員」が選べない場合は、大学の Workspace 管理設定で匿名アクセスの Web アプリが制限されている。情報管理部門・Workspace 管理者に確認し、不可なら README §7.3 案 B（Google フォーム）に切り替える。

## 5. 動作テスト

- 関数 `testPostDummy` を実行すると、ダミー患者（番号 9001、暗証番号 0000）を患者一覧に追加し、赤信号の送信をシミュレートする。日次記録に行が入り、即時通知メールが届き、全体サマリーと「進捗_9001」タブが更新されれば成功
- 実患者のデータでテストしない。テスト後はダミー行を削除してよい（`status` を `inactive` にしてもよい）

## 6. コードを更新したとき

貼り直して保存した後、**デプロイ → デプロイを管理 → 編集（鉛筆）→ バージョン: 新バージョン → デプロイ**。URL は変わらない。

## 関数一覧

| 関数 | 役割 | 実行 |
|---|---|---|
| `setupSheets` | タブ・見出し・保護を作成 | 初回手動 |
| `installTriggers` | 時間主導トリガーを設定 | 初回手動 |
| `doGet` | 疎通確認 | Web |
| `doPost` | 患者送信の受信・検証・保存・即時通知（赤信号・運動後症状のみ） | Web |
| `dailySummary` | 朝のまとめメール | トリガー 8:00 |
| `weeklySummary` | 週次実施率メール | トリガー 月曜 8:15 |
| `refreshDashboard` | 全体サマリーと患者ごとの日次シート（進捗_番号）の再計算 | 毎時＋受信時 |
| `testPostDummy` | ダミー送信テスト | 手動 |

## 受信時の検証

- 4 桁の番号と 4 桁の暗証番号。`SHA-256(番号:暗証番号)` と患者一覧の `pin_hash` の一致
- 連続 10 回失敗で 6 時間ロック（設定タブで変更可）
- `status` が `active` であること
- 番号ごとに 1 分 10 回まで（設定タブで変更可）
- `action: "verify"` の場合は照合のみ行い、メニュー種別を返す（アプリの初期設定時）
- 同一 `study_id`・`log_date` の再送信は上書き
