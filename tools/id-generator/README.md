# 番号・暗証番号 発行ツール

院内 PC で `index.html` をブラウザ（Chrome / Edge）で開いて使う。通信は行わない。

## 使い方

1. 次に発行する番号（4 桁、1001 から）とメニューテンプレートを確認して **発行する**。暗証番号は推測されにくい 4 桁が自動生成される
2. 「患者一覧タブに貼り付ける行」をコピーし、スプレッドシート「患者一覧」の空行に貼り付ける。担当者メールを追記する
3. 「REDCap 等に登録する内容」を参考に、院内システムに番号と患者の対応を登録する（暗証番号は登録しない）
4. **印刷** でカードを印刷し、入院時にスタッフが患者のスマートフォンに一緒に入力する。カードは患者が保管

## 仕組み

- アプリの初期設定で番号と暗証番号を入力すると、Apps Script が `SHA-256(番号 + ':' + 暗証番号)` を患者一覧の `pin_hash` と照合し、メニュー種別を返す
- 暗証番号の平文はカードにしか存在しない。スプレッドシートにはハッシュのみ
- 連続 10 回失敗すると 6 時間ロックされる（Apps Script の設定タブで変更可）
- 端末紛失・利用終了時は患者一覧の `status` を `inactive` にする。番号を再発行する場合は新しい行を追加する

## 注意

- 番号はブラウザに保存されるが、複数 PC で発行する場合は院内システムの最終番号を確認してから発行する
- 9001〜9999 はテスト用に予約（モックサーバーのテスト患者は 9001 / 9002）
